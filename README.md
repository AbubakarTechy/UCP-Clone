# UCP Portal Clone

A lightweight front-end recreation of a university student portal, built with semantic HTML, CSS, and vanilla JavaScript.

> **Demo project:** The student profile, course details, grades, and attendance values shown in this repository are sample content for a front-end practice project. This is not an official University of Central Punjab portal and it does not connect to university systems.

## Project goals

- Practice building a dashboard layout with HTML and CSS.
- Present student information and academic summaries in a clear interface.
- Make the course list usable on desktop, tablet, and mobile screens.
- Add small client-side interactions without a framework.

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript

## Run locally

No build tools or package installation are required.

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a modern browser.

For a local development server, you can also use the VS Code Live Server extension.

## Project files

| File | Purpose |
| --- | --- |
| `index.html` | Dashboard structure and sample academic content |
| `style.css` | Layout, visual styling, and responsive breakpoints |
| `app.js` | Client-side course search and interface behavior |
| `logo_org.png` | Logo image used in the demo |
| `download` | Original project asset |

## Interface features

- Semantic page landmarks and descriptive navigation labels.
- Student overview with academic summary cards and a sample class schedule.
- Course cards with attendance progress indicators and credit-hour labels.
- Live course search across course names, instructors, and course codes.
- Keyboard support: press Escape in the search field to clear the filter.
- Responsive layouts for desktop, tablet, and mobile screens.
- Reduced-motion preference support and visible keyboard focus styles.

## Scope and privacy

This repository is a static front-end demo. It has no authentication, backend, database, or official university integration. Do not enter real passwords or sensitive student information into a static demo.

## Possible improvements

- Connect the interface to a secure backend and real data source.
- Add accessible grade and attendance details.
- Introduce automated accessibility and responsive-layout checks.
