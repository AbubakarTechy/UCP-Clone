# Security policy

## Project scope

UCP Portal Clone is an educational, static front-end demonstration. It has no authentication service, server-side authorization, database, or official university integration.

All student, course, grade, and attendance information displayed by the interface is sample content. Do not enter real credentials, personal records, or confidential university information.

## Reporting a concern

Please do not publish passwords, private student records, or other sensitive information in a public issue. For a security concern involving this repository, contact the repository maintainer privately through the contact options on the GitHub profile.

## Responsible use

Do not present this demo as an official university service or use it to collect real student credentials.
