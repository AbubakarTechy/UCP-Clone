# Accessibility Checklist

This document records accessibility checks for the static portal interface.

## Semantic structure
- [ ] Use one descriptive page-level heading.
- [ ] Keep navigation inside a labelled `nav` landmark.
- [ ] Use headings in a logical order.
- [ ] Use buttons for actions and links for navigation.

## Keyboard support
- [ ] Verify every interactive control is reachable with Tab.
- [ ] Verify focus indicators remain visible.
- [ ] Verify the skip link moves focus to the main content.
- [ ] Verify search shortcuts do not interfere with typing in form fields.

## Assistive technology
- [ ] Confirm course result updates are announced through the status region.
- [ ] Confirm progress bars have accessible labels and numeric values.
- [ ] Confirm icon-only or text-light controls have accessible names.

## Visual preferences
- [ ] Check text and control contrast in both themes.
- [ ] Test browser zoom at 200%.
- [ ] Check the reduced-motion preference.
- [ ] Do not communicate status through color alone.

This is a review checklist, not a claim of formal WCAG certification.
