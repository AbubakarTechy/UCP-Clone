# Project Scope

## Purpose
UCP Clone is a front-end practice project that recreates the layout of a university student portal. It is an unofficial demonstration and is not connected to University of Central Punjab systems.

## In scope
- Student dashboard layout and sample academic summary.
- Course cards with sample attendance values.
- Client-side course search, sorting, and attendance filtering.
- Theme preference, print view, and CSV export.
- Responsive presentation for common screen sizes.

## Out of scope
- Real student accounts or authentication.
- Access to university records, grades, or attendance systems.
- Payment, fee challans, registration, or transcript services.
- Server-side persistence or role-based access.

## Data disclaimer
All student, course, instructor, grade, and attendance details displayed in the demo are illustrative. Do not use this interface to submit or store real credentials or sensitive student data.
