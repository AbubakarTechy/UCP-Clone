# Browser Support

The project uses standard HTML, CSS, and browser JavaScript APIs.

## Review targets
- Current stable Chrome and Edge.
- Current stable Firefox.
- Current stable Safari.
- Mobile browsers on Android and iOS.

## Compatibility checks
- Confirm CSS grid and flex layouts render correctly.
- Confirm local storage failures do not stop the page from working.
- Confirm media-query preferences are handled safely.
- Confirm CSV download works in the target browser.
- Confirm print styles produce readable output.

This list identifies browsers to test; it is not a formal compatibility certification.
