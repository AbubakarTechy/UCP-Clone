# Project Roadmap

This roadmap records possible improvements for the static portal demo. Items are proposals, not promises or claims that the functionality already exists.

## Interface improvements
- [ ] Add a dedicated course detail view with sample assessment breakdowns.
- [ ] Add a timetable view grouped by weekday.
- [ ] Add a compact mobile navigation pattern.
- [ ] Add a confirmation or success message after CSV export.

## Quality improvements
- [ ] Add automated browser tests for search, sorting, filters, and theme behavior.
- [ ] Add an accessibility review using keyboard-only navigation and a screen reader.
- [ ] Add visual regression checks for the main responsive breakpoints.
- [ ] Test local-storage behavior when browser storage is blocked or malformed.

## Future architecture
- [ ] Define a documented API contract before connecting a backend.
- [ ] Add authentication and role-based authorization only with a secure server.
- [ ] Replace sample academic data with an authorized, privacy-reviewed data source.

The current repository remains a static front-end demonstration until those architectural changes are implemented.
