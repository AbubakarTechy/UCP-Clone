# Possible Future Improvements

The following ideas are exploratory and are not implemented features.

## Interface

- Add a more detailed accessible course information view.
- Improve timetable presentation for different screen sizes.
- Add clearer empty and loading states if asynchronous data is introduced.

## Quality

- Add repeatable automated checks if the project grows beyond a small static demo.
- Add accessibility checks to the review workflow.
- Capture reference screenshots for key viewport sizes.

## Data integration

A secure backend and authorized data source could be considered only with appropriate permission, privacy review, and a defined data model. Do not connect this demo to real student records without those safeguards.
