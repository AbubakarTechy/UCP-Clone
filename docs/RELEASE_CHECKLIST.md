# Release Checklist

Before publishing an updated version of the demo:

- [ ] Open the page from a clean browser session.
- [ ] Check all relative asset paths.
- [ ] Verify course search, filtering, and sorting.
- [ ] Verify theme selection and preference fallback.
- [ ] Verify CSV export and print layout.
- [ ] Review keyboard navigation and focus visibility.
- [ ] Check the mobile layout at narrow widths.
- [ ] Review the browser console for errors.
- [ ] Confirm sample-data and unofficial-project disclaimers are visible.
- [ ] Ensure no credentials, tokens, or private student data are committed.

A release should only be marked complete after the relevant checks have actually been performed.
