# Release Checklist

Before publishing an updated static demo:

- [ ] Open `index.html` directly or through a local static server.
- [ ] Confirm `style.css`, `app.js`, and image assets load successfully.
- [ ] Review sample-data and unofficial-demo disclaimers.
- [ ] Complete the manual interaction test plan.
- [ ] Check desktop, tablet, and narrow mobile layouts.
- [ ] Verify keyboard focus, skip navigation, and reduced-motion behavior.
- [ ] Test CSV export with both filtered and unfiltered course lists.
- [ ] Inspect the print preview.
- [ ] Check browser console output for errors.
- [ ] Review changed files and commit messages before publishing.

This checklist describes a manual static-site release process; it does not imply an automated deployment pipeline.
