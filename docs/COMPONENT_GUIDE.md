# UI Component Guide

This guide describes the main visual sections in the current static interface.

## Header
Contains the project identity, in-page navigation, demo label, and theme control.

## Student profile
Shows illustrative student identity and academic-standing information.

## Summary cards
Present sample CGPA, credit-hour, and attendance metrics.

## Schedule panel
Displays sample class timetable entries.

## Course cards
Show a course code, title, instructor, credit value, attendance percentage, and term note.

## Course controls
Provide text search, sorting, attendance filtering, clearing, and an empty state.

## Footer
Repeats the unofficial-demo context.

These are front-end presentation components; they are not backed by a university data service.
