# Responsive Layout Notes

The stylesheet uses two primary viewport breakpoints.

| Viewport | Layout behavior |
| --- | --- |
| Above 900px | Four summary cards and three course columns |
| 621px–900px | Two summary columns and two course columns |
| 620px and below | Single-column course and timetable layouts, stacked section headings, and full-width form controls |

The header wraps on small screens so the primary navigation can move to its own row. The profile panel stacks its identity and academic-standing sections on mobile.

## Verification

Check the dashboard at 1440px, 900px, 768px, 620px, 390px, and 320px widths. Confirm there is no horizontal page overflow, controls remain reachable, and course titles wrap without overlapping attendance values.
