# Keyboard Navigation

The dashboard supports the following keyboard interactions.

| Key or action | Result |
| --- | --- |
| Tab | Move to the next focusable control |
| Shift + Tab | Move to the previous focusable control |
| Enter or Space | Activate a focused button or link |
| Escape in course search | Clear the query and leave the search field |
| / outside editable controls | Focus the course search field |
| Skip to main content link | Move directly to the main dashboard |

The slash shortcut is ignored while the user is typing in an input, textarea, select, or editable element. Browser and assistive-technology shortcuts may take precedence.

## Adding shortcuts

Keep shortcuts discoverable and avoid overriding common browser or assistive-technology commands. Every important action must remain available through visible controls.
