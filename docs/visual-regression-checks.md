# Visual Regression Review Points

Use the same browser zoom and viewport dimensions when comparing screenshots across changes.

## Desktop

- Header alignment and navigation spacing
- Welcome section and action buttons
- Profile panel and academic summary cards
- Two-column timetable
- Three-column course grid

## Tablet

- Two-column summary and course grids
- Wrapping of section headings and controls
- No clipped course titles or action buttons

## Mobile

- Wrapped header and navigation
- Stacked profile panel
- Single-column timetable and course list
- Full-width search and filter controls
- No horizontal page scrolling

## Theme review

Compare light and dark themes for text contrast, borders, progress tracks, badges, and form controls. Visual checks complement functional and accessibility testing.
