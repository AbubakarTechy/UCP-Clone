# Demo Content Guidelines

This repository is an unofficial interface practice project. Content must not imply that the page is an official university system.

## Content rules

- Keep sample student, instructor, course, and attendance data clearly identified as illustrative.
- Do not add real passwords, private records, or sensitive student information.
- Avoid claims that the displayed grades or attendance are current or verified.
- Preserve the disclaimer in the page and README when updating visible content.
- Use neutral example values in screenshots and documentation.

If the project later connects to a real data source, review authorization, privacy, accuracy, and institutional permission separately before adding that integration.
