# Dashboard Interaction Reference

| Control | Expected behavior |
| --- | --- |
| Dashboard navigation | Moves to the dashboard section |
| Academics navigation | Moves to the course section |
| Theme toggle | Switches between light and dark presentation |
| Print dashboard | Opens the browser print dialog |
| Export courses | Downloads visible course rows as CSV |
| Course search | Matches text across each course card |
| Clear search | Removes the current search query |
| Course sort | Orders visible cards by default, name, or attendance |
| Attendance filter | Restricts cards by attendance threshold |
| Reset filters | Restores the unfiltered default course list |

The interface is a static demo. These controls do not submit data to a university service.
