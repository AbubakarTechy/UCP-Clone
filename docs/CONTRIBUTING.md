# Contributing

Thanks for helping improve this student portal interface demo.

## Development setup
1. Clone the repository.
2. Open the project folder in your editor.
3. Open `index.html` in a modern browser, or use the VS Code Live Server extension.
4. No package installation or build step is required.

## Change guidelines
- Keep the implementation compatible with plain HTML, CSS, and vanilla JavaScript.
- Prefer small, focused changes.
- Use semantic HTML and preserve keyboard accessibility.
- Keep the responsive layout working at mobile, tablet, and desktop widths.
- Keep all profile and academic values clearly identified as sample data.
- Avoid adding secrets, real student records, or private credentials.

## Before submitting
- Follow the checks in [the manual testing checklist](TESTING.md).
- Review the changed files for accidental unrelated edits.
- Use a concise commit message that describes the user-visible change.
