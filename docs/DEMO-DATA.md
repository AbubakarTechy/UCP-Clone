# Demo Data and Privacy

UCP Portal Clone is an independent front-end practice project. It is not an official University of Central Punjab service and does not connect to university systems.

## Sample content
The profile, student identifier, CGPA, credit hours, timetable, course names, instructors, and attendance percentages displayed in the interface are demonstration content. They must not be treated as verified academic records.

## Data handling
- The project has no server, authentication system, or database.
- Search, sorting, and theme preferences may be stored in the browser's local storage.
- Course export creates a CSV file locally in the browser.
- The static demo should not be used to collect passwords, identity documents, or confidential student records.

## Safe extension
If a backend is introduced later, use authenticated APIs, server-side authorization, input validation, secure session handling, and a clear data-retention policy. Never publish real student information in a public repository.
